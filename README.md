# Commercial Sales Performance & Revenue Analytics

Interactive Microsoft Excel dashboard developed to analyze commercial sales performance and generate actionable business insights.

## Project Overview
Analyzed 1,000+ sales transactions representing ₹17.8M+ in revenue to evaluate revenue trends, product performance, seller performance and payment patterns.

## Key Analysis
- Revenue and sales trend analysis
- Product performance analysis
- Seller performance benchmarking
- Revenue concentration analysis
- Identification of underperforming segments
- Business insights and recommendations

## Tools & Techniques
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- KPI Analysis
